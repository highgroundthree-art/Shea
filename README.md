# Shea

Marketing landing page: cleaning-supply safety for healthcare professionals, daycares, home care providers and foster care providers.

## Files
- `index.html`: the whole page (no build step, no external dependencies)

## Fill in before publishing
- The brand name "Shea" is a working name. Replace it if needed.
- "How we help" section: describe the actual offering (marked with brackets).
- Footer: business name, address, contact details.
- Contact form: it currently opens an email to `hello@example.com`. Change the address, or connect a form service.
- Review all safety wording against your product labels, SDS sheets and any regulatory requirements. No certifications, statistics or product claims are included on purpose.

## Publish
Turn on GitHub Pages (Settings, Pages, deploy from `main`, root). Pages from a private repo needs a paid GitHub plan, and the published site is public.
